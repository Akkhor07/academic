Group project · Motor design · Feedback control

Smart DC motor with autonomous speed control

We built the motor itself, from the wound armature to the magnet housing, then closed the loop: PWM drive with real-time speed feedback holds a target RPM under changing load. A keypad sets the target. Group project, 2022.

Group project · OpenCV CSRT · PID

Tracking and stabilization with computer vision and PID control

A webcam on a servo follows a moving target. OpenCV’s CSRT tracker locates the target in each frame, and a PID controller turns the servo to keep it centred. Evaluated on rise time, overshoot and steady-state error. Group project, 2023.

Group project · SolidWorks · Arduino

Industrial robotic arm prototype

A multi-DOF pick-and-place arm designed in SolidWorks and built with servo motors and an Arduino Mega, with inverse kinematics for precise positioning. Group project, 2023.

Code and experiments are on github.com/Akkhor07.
